# Musilog

黄色（#ffce0a）と既存ロゴを活かした、Web制作者のホームページ兼ブログ用WordPressテーマです。

## 内容の設定

「外観 → カスタマイズ → Musilog：プロフィール・お仕事」で、以下を編集できます。

- トップページの見出し・紹介文
- プロフィールの表示名・肩書き・自己紹介・画像・詳細ページURL
- お問い合わせページURL

お問い合わせURLが未設定の場合は、公開済みの `inquiry`、`contact` ページの順で使用します。ローカルにない場合は、実際の公開フォーム https://musilog.net/inquiry/ にリンクします。フォームの送信処理はテーマに含みません。

「外観 → ウィジェット」の「ブログサイドバー（プロフィールの下）」にウィジェットを追加できます。未設定時は検索・既存の4カテゴリーへの入口・最近の記事を表示します。プロフィールと制作相談リンクは常に表示されます。

メニューを割り当てていない場合は、ホーム・Web制作・ブログ・プロフィールを自動表示します。既存の割り当て済みメニューはその内容を使用します。

## ページ構成

- トップ：制作紹介、サービス、既存カテゴリー、選定記事3件、最新記事6件、プロフィール、相談案内
- ブログ・アーカイブ・検索：記事カードとサイドバー
- 記事：本文、著者紹介、関連記事、前後記事、コメント、サイドバー
- スマートフォン：1列レイアウト、開閉式メニュー

投稿ページを「設定 → 表示設定」で指定している場合、ブログリンクはそのページを使用します。未指定の場合は `?musilog_blog=1` で記事一覧にアクセスできます。固定フロントページに既存の本文があれば、トップページの最新記事セクションの後に表示します。

紹介文やサービス説明は初期文案です。公開前に実際のプロフィール・対応内容・相談先に合わせて調整してください。既存の記事やデータベースの設定は変更していません。

## 公開ブログに合わせた編集（2026-09-07）

公開プロフィールと記事を参照し、脇村 隆（wackey）のWebディレクション・ブログ運営の経験、2006年からの発信を初期文案に反映しました。実績の件数・顧客名・料金は追加していません。

「外観 → カスタマイズ → Musilog：はじめての方へ」から、選定記事の見出し・紹介文・URLを変更できます。カードの見出しは記事の紹介用コピーです。

- プロフィール：https://musilog.net/about/
- フリーランスとしての活動：https://musilog.net/shigoto-memo/business-management/17826/ （トップページのタイトル・概要を参照）
- テーマ制作の実践：https://musilog.net/web-memo/blog/17145/
- Macでの作業効率化：https://musilog.net/shigoto-memo/macpc/14924/
- 問い合わせ：https://musilog.net/inquiry/

カテゴリーは既存の `web-memo`・`shigoto-memo`・`kurashi-memo`・`spot` をスラッグで参照します。記事・カテゴリー・aboutページがローカルにない場合は、確認済みの公開URLへリンクします。本番の既存カテゴリーや記事のURLを変更する処理はありません。テーマの表示時に外部サイトからデータ取得することもありません。

本番の記事本文・画像はローカルDBにインポートしていません。「最近のメモ」「最近の記事」と検索は、そのWordPress環境に登録されている投稿を使います。
